# 02 · 串口帧协议与解析

## 帧格式（115200 8N1）

摄像头模块以文本帧输出人脸框左上/右下角像素坐标：

```
$x1,y1,x2,y2,#
```

人脸识别模式尾部附加 `@ID:n` 标识已注册人员编号，可实现"只跟踪特定人"。

模块的其它输出（版本号、WiFi 状态 JSON 等）不匹配帧格式，被状态机自然过滤。

## 坐标换算（STM32 端）

```
cx = (x1 + x2) / 2,  cy = (y1 + y2) / 2      # 人脸框中心
dx = cx - CAM_CENTER_X                        # 水平偏差（像素）
dy = cy - CAM_CENTER_Y                        # 俯仰偏差（像素）
w  = x2 - x1                                  # 框宽 → 用于单目测距
```

画面中心按 QVGA 320×240 假设，联调时通过 `CAM_CENTER_X/Y` 宏校准。

## 接收链路

1. **中断层**：`HAL_UART_RxCpltCallback` 单字节接收，入 FreeRTOS 消息队列 `uart3_rx_q`（64×uint8_t），超时 0 不阻塞；
2. **任务层**：esp32linkTask 阻塞出队，以 `\n` 为界拼帧；
3. **解析层**：帧头 `$` 校验 + `sscanf` 提取坐标，超长帧丢弃重新同步，写入 `g_target`。

## 模式控制命令

通过调试串口向模块转发（不带回车换行）：

| 命令 | 作用 |
|------|------|
| `wifi_ver` | 查询固件版本 |
| `ai_mode:2` | 人脸检测模式（断电保持） |
| `ai_mode:4` | 人脸识别模式（录脸 / 识别 / 删脸） |
