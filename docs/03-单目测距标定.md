# 03 · 单目测距与标定

## 原理

取消独立激光测距模块，利用成像几何关系直接由人脸框宽度反算距离：

```
dist_mm = K / w        w = 人脸框像素宽度
```

依据针孔模型：目标物理尺寸近似恒定（人脸宽度先验 ≈150mm）时，像宽与距离成反比。距离信息与偏差共用同一条 USART3 链路，硬件零新增。

## 标定

人站已知距离 D，读稳定人脸框宽度 w：

```
K = D × w
```

实测标定数据（2026-09-07）：

| 距离 D | 框宽 w | K |
|--------|--------|------|
| 400mm | 172px | **68800** |

## 验证

| w (px) | 反算距离 | 
|--------|----------|
| 172 | 400mm ✓ |
| 100 | 688mm |
| 86 | 800mm |

精度 ±5~10%，依赖标定距离与使用距离接近、正脸假设；侧脸与运动模糊造成的框抖动由 distTask 8 点滑动平均滤波抑制。

## 滤波

distTask 以 50ms 周期维护 8 点环形缓冲滑动平均，目标丢失时清零缓冲并输出无效值，避免残留数据影响显示与上报。
