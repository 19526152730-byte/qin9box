# 04 · 硬件接线与供电

## 引脚分配

| 外设 | 引脚 | 外设 | 引脚 |
|------|------|------|------|
| USART2 调试 | PA2(TX) / PA3(RX) | TIM4_CH1 水平舵机 | PD12 |
| USART3 视觉帧 | PB10(TX) / PB11(RX) | TIM4_CH2 俯仰舵机 | PD13 |
| USART6 ESP8266 | PC6(TX) / PC7(RX) | I2C1 OLED | PB6(SCL) / PB7(SDA) |
| LED1~6 状态灯 | PD4~PD9 | SWD | PA13 / PA14 |

时钟树 168MHz，HSE 8MHz；FreeRTOS 时基使用 TIM6（SysTick 留给 HAL）。

## 供电（三路独立，全部共地）

```
① 5V/2A 电源模块 ── SG90 ×2（峰值 1.5A，严禁吃板载 3.3V）
② DAPLink Type-C ── 板载 LDO 3.3V ── STM32 + OLED + ESP8266（约 300mA < 保险丝 500mA）
③ ESP32-S3 独立 Type-C
```

## 接线要点

- ESP8266-12F 的 EN 必须拉高；峰值电流约 350mA；
- 舵机与主控必须共地；
- OLED I2C 地址 0x3C，总线 400kHz Fast Mode；
- ESP32-S3 与 STM32 串口交叉连接：S3 TX → PB11，S3 RX → PB10。
